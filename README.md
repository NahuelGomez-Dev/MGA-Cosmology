## 📖 Overview

This repository contains the numerical simulation framework for **MGA Cosmology**, an effective braneworld model in which our observable universe $M_H$ emerges as the interior of a dynamical event horizon generated by stellar collapse in a parent universe $M_P$.

The code numerically integrates the **closed modified Friedmann equations** derived in the companion paper, validating three key predictions:

1. **Quantum Bounce**: The torsion fluid ($\rho_T \propto a^{-6}$) prevents the initial singularity, producing a bounce at finite minimum scale factor $a_{\min} > 0$ with inverted curvature ($\ddot{a} > 0$).
2. **Emergent Dark Energy**: A boundary dilaton field $\Phi$ decays at rate $\Gamma$ (derived from Bogoliubov mode-matching), sourcing a dynamic dark energy component.
3. **Three-Phase Cosmic History**: Torsion-dominated bounce → radiation-dominated expansion → dilaton-dominated accelerated expansion.

### Governing Equations

| Equation | Expression | Reference |
|----------|------------|-----------|
| **First Friedmann** | $H^2 = \frac{8\pi G}{3}[\rho_m + \rho_\Phi - \rho_T] - \frac{k}{a^2}$ | Eq. 7.4 |
| **Acceleration** | $\frac{\ddot{a}}{a} = -\frac{4\pi G}{3}[\rho_m + 3p_m + \rho_\Phi + 3p_\Phi - (\rho_T + 3p_T)]$ | Eq. 7.5 |
| **Dilaton continuity** | $\dot{\rho}_\Phi = -[3H(1+w_\Phi) + \Gamma]\rho_\Phi$ | Eq. 7.9 |
| **Equation of state** | $w(t) = -1 + \frac{\Gamma}{3H(t)}$ | Eq. 7.11 |

## 🚀 Quick Start

### Installation

```bash
git clone https://github.com/NahuelGomez-Dev/MGA-Cosmology.git
cd MGA-Cosmology
pip install -r requirements.txt
```

### Basic Usage

```python
from src.mga_cosmology import MGACosmology, ModelParameters

# Configure the simulation
params = ModelParameters(
    Gamma=0.01,        # Dilaton decay rate (from Eq. 6.8)
    w_m=1/3,           # Radiation equation of state
    w_Phi=-1.0,        # Dilaton (slow-roll dark energy)
    w_T=+1.0           # Torsion (stiff bounce fluid)
)

# Run simulation
sim = MGACosmology(params=params)
results = sim.run()

# Visualize and export
sim.plot(save_path="output/bounce_and_densities.png")
sim.export_csv("output/simulation_data.csv")
print(sim.summary())
```

### Advanced: Parameter Sweep

```bash
python examples/parameter_sweep.py
```

Explores how the dilaton decay rate $\Gamma$ (proportional to $M_\bullet^{-3}$, the parent black hole mass) affects the late-time dark energy dominance.

## 🔬 Scientific Context

### What is MGA Cosmology?

MGA (Matrioshka-Genesis-Accretion) addresses three foundational problems in ΛCDM:
1. **Initial singularity** → Resolved by Einstein–Cartan torsion bounce
2. **Dark energy origin** → Derived from boundary dilaton decay
3. **Cosmological constant fine-tuning** → $\Lambda_{\text{eff}}(t) = \Lambda_0 e^{-\Gamma t}$ emerges dynamically

### Unique Observational Prediction

The model predicts a **cross-correlation** between the dark energy equation-of-state deviation $\delta w(z)$ and the supermassive black hole mass distribution at $z \sim 2$–$6$, testable by **DESI**, **Euclid**, and **LSST**.
